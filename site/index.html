在微信网页中生成 App 唤起开放标签

配置微信 JS-SDK 签名、生成 wx-open-launch-app 标签，并集中处理就绪、唤起和失败回调。

打开 Playground浏览 API

安装

从 npm 安装库，并通过默认导出的工厂函数创建实例。

npm install mazey-wechat-launch-app

基本用法

传入 JS-SDK ticket、公众号 AppID、移动应用 AppID 和目标容器选择器，然后调用 start()。 

import createLaunchApp from 'mazey-wechat-launch-app';

const launchApp = createLaunchApp({
  weixinJsSdkTicket: ticket,
  serviceAccountAppId: 'wx-service-account-app-id',
  openPlatformMobileAppId: 'wx-mobile-app-id',
  launchContainerQuery: '.launch-app-button',
  extInfo: 'product=123',
});

launchApp.start();

功能范围

库负责开放标签与微信 JS-SDK 集成；业务方仍需从可信服务端获取 ticket，并决定失败跳转与交互文案。

开放标签

为匹配的容器生成 wx-open-launch-app。

生命周期

提供就绪、点击、更新和销毁相关方法。

分享配置

支持微信好友与朋友圈分享配置。
